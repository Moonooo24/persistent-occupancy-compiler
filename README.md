# Persistent occupancy compiler

Reproducibility artifact for *Constraint-Preserving Quantum Circuit Compilation for Graph Independent Sets via Persistent Occupancy Encoding*.

The compiler discovers true-twin classes, maintains the occupancy encoding on the original data register, and selects a complete circuit using measured resources. An optional topology maps and restores the logical wire order. The artifact contains the compiler, fixed case specifications, baselines, correctness checks, paired measurements, and English figure sources.

## Quick verification

Use Python 3.11.5 on Windows or Python 3.12.3 on Linux. Install the corresponding pinned requirements from the repository root. The paper's main run uses Qiskit 2.1.2.

```sh
python -m pip install -r requirements_windows.txt
python -B code/smoke.py
python -B code/summarize_results.py
```

On Linux install `requirements_server.txt` instead. The smoke test compiles the seven-vertex graph to the native basis and to a grid, restores the original wire order, and compares complex amplitudes including global phase on the feasible subspace. The complete circuits, test output, and construction certificates are written to `results/smoke/`. A saved native circuit and certificate are also in `examples/`. Use `runtime.io.load` to load these QPY artifacts with the pinned SDK and the project's phase-preserving envelope.

The recorded-result check uses the actual per-program candidate and reference records. It reconstructs:

## Rebuild circuits

The programmatic entry point is `code/journal_api_v3.py`, function `compile(problem, target=None, include_shared=False)`. The target can be `line` or `grid`. JSON examples specify the graph, sweep count, target order, and weights.

For public graphs, the catalog identifies the original CMU COLOR inputs by URL and SHA-256. The preparation script validates all 12 source files and produces 24 cases using the recorded target orders. It also checks the normalized edge-set digest for every case. If you already downloaded the original files, pass `--local-dir PATH`.

```sh
python -B code/prepare_public_inputs.py
python -B code/run_artifact.py --group public24 --case myciel3__ascending --method ours_all
python -B code/run_artifact.py --group public24 --case myciel3__ascending --method ref_matched_exact_clique
```

The final reported CX counts for this pair are 226 and 260. The runner also supports `main144`, `new_confirmation72`, `sweep120`, `controlled`, and `routing`. For example:

```sh
python -B code/run_artifact.py --group main144 --limit 1
python -B code/run_artifact.py --group main144
python -B code/run_artifact.py --group routing --limit 1 --method ours_hop
```

The main catalog runs the 134 semantic programs in the paper. The recorded data retain the 144 original rows and their semantic identifiers for verification of the deduplication. Each catalog benchmark uses the fixed baseline set for its cohort. Run optional supplementary baselines by passing their method IDs, e.g. `ref_quclear_seq` or `ref_quclear_tree`. The recorded tables preserve completion coverage and distinguish ties from reductions.

The Qiskit level-1 check uses the same all-to-all basis, fixed transpiler seed and phase policy as the paper. Run it on a logical `post.qpy` output with `python -B code/level1.py INPUT.qpy OUTPUT.qpy`. Recorded per-method measurements are in `data/level1_method_metrics.csv`. Code-level gate recipes and checks are in `verify_explicit_kernel_recipes_v2.py` and `verify_v2_phase_generic.py`. Large QPY files are regenerated by the runners. The paper's recorded circuit measurements can be read directly without those files.

## Figures, timing and provenance

- Figures 2–6 use the paired resources in `data/evaluation.json`, the controlled ablations and topology summaries in `data/review_statistics.json`, and the two timing datasets. Figure 1 is the vector workflow illustration.
- Run `python -B code/draw_results_en.py` and `python -B code/draw_combined_en.py` to rebuild the experiment plots in `paper/figures/`. The scripts use Times New Roman. Set `JOURNAL_FONT_DIR` to a directory containing the four Times New Roman font files if needed. Pre-rendered vectors are available in `figures/`.
- On Linux, `python -B code/end_to_end_profile_worker_v2.py --index 0` runs one of the 12 complete-entry timing jobs. The indices run from 0 to 11. For the Windows single-path timings, use `code/scaling_worker_v2.py` with a case from `protocols/scaling_v2/`, mode `all` or `selected`, and trial `0`, `1`, or `2`. Archived timings are hardware dependent.
- `protocols/artifact_source_lock.json` identifies the exact byte versions included here and records the original experiment source-lock digest. `data/recorded_provenance.json` lists digests of the original result collections used to curate the public records.
- Third-party redistribution terms and attribution are in `third_party/`. CMU COLOR graph downloads are described in `data/public_inputs.json`.
